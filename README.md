# Seesaw Simulation

Interactive physics-based seesaw simulation built with vanilla JavaScript.

## Author
**Ahmet Bahadır Ayar**

## Features
- Interactive weight placement
- Real-time torque calculation
- Smooth tilt animations
- Weight drop animations
- Persistent state (localStorage)
- Weight history tracking

## Technologies
- HTML5
- CSS3 (Custom Properties, Animations)
- Vanilla JavaScript
- LocalStorage API
